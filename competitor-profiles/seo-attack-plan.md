# ClearWork — SEO & Competitive Attack Plan

**Created**: 2026-08-20
**Based on**: Research across Refrens, Zoho Invoice, HoneyBook, Bonsai, Dubsado, and the Indian freelancer tool SERP landscape.

---

## The One Insight That Drives Everything

**India has no all-in-one freelancer workflow platform.**

Zoho Invoice: free invoicing, no proposals, no contracts.
Refrens: deep GST accounting, no contracts, no client portal.
HoneyBook/Bonsai/Dubsado: have everything — but explicitly do NOT serve India (USD only, HoneyBook waitlists India).

Every Indian freelancer searching for "bonsai alternative india" or "dubsado alternative india" is a pre-qualified, ready-to-buy user with **zero Indian competitor to land on**. ClearWork is the answer to a question no one has answered yet.

## SEO Strategy: Three Tiers

### Tier 1 — Own Now (near-zero competition, high buyer intent)

These keywords have almost no existing Indian content. ClearWork can rank on page 1 quickly with a single well-structured landing page each. Build these first.

| Target URL | Target Keyword | Why Low Competition | Conversion Potential |
|---|---|---|---|
| `/alternatives/dubsado-alternative-india` | "dubsado alternative india" | No Indian competitor covers this — Dubsado is USD-only, has no India page | Very high — user is actively looking to switch |
| `/alternatives/bonsai-alternative-india` | "bonsai alternative india" | Bonsai has no INR pricing, no GST — zero Indian tools target this | Very high |
| `/alternatives/honeybook-alternative-india` | "honeybook alternative india" | HoneyBook explicitly waitlists India — this user CANNOT use HoneyBook | Extremely high |
| `/features/proposal-software-india` | "proposal software for freelancers india" | No Indian tool has a proposal builder — Zoho doesn't, Refrens doesn't | High — transactional |
| `/features/contract-software-india` | "freelance contract software india" | Zoho Sign exists but isn't freelancer-workflow-native; no bundled tool | High — transactional |
| `/features/client-portal-india` | "client portal for freelancers india" | No Indian tool has a dedicated client portal | High — transactional |

**Page structure for each Tier 1 page:**
1. H1: "The best [tool] alternative in India for freelancers"
2. Hero: Why [tool] doesn't work for India (USD pricing, no GST, no UPI, no IT Act e-sign)
3. Feature comparison table (their features vs. ClearWork's features, INR pricing)
4. "What you get with ClearWork" section
5. Testimonial / social proof
6. CTA: "Get started — it's free"
